Agent Kill Switch
DemoFAQ

How it works

AI agents hold wallets and act on their own. When one goes wrong, its owner needs to stop it instantly, and everyone it deals with needs to see that it was stopped. This is that switch, with Monad validators as the witnesses.

Who is involved

The agenta program with its own wallet. It trades, pays, and signs on its own.
The ownerthe person behind the agent. Holds a separate cold key that can only stop the agent, never spend.
The exchangeany app the agent uses. Before doing anything for the agent, it asks the switch: is this agent still allowed?
The validatorsMonad validators who opted in as operators. They post a bond and sign a notice when a stop happens, so the stop can be trusted without asking the owner.

What happens, step by step

  1. Register. The owner registers the agent once: the agent's key, the owner's cold key, and optionally a few guardians. The agent starts as active.
  2. Act. Every app the agent uses checks the switch inside the same transaction. Active means go. Anything else means the transaction fails on chain, so there is no list to sync and no API to trust.
  3. Stop. The owner sends one transaction from the cold key. The agent is revoked. Revoked is permanent. The next block already refuses it, which on Monad is a fraction of a second later.
  4. Confirm. Operators see the stop and sign a short notice: this agent was revoked. Their signatures are combined into one, so checking it costs the same whether two operators signed or two hundred.
  5. Recover. The owner can register a successor agent and point the old id at it, so anyone who trusted the old agent knows where trust moved.

Why validators

A notice is only worth something if the signer has something to lose. Operators are validators in Monad's active set, checked against the chain every epoch, and each one posts a bond. If an operator signs a claim that the chain shows is false, anyone can present the proof and take the bond. Reputation, stake, and uptime history all sit behind every signature.

Why Monad

Three things make this practical here and awkward elsewhere. Blocks are 300 milliseconds and final in 600, so a stop lands before the agent's next action. The BLS precompiles are live, so combined validator signatures verify with one cheap operation. And the staking precompile lets a contract read the validator set directly, so operator membership is a fact from the chain, not a list we keep.

What it is not

It is not a reputation score. It records facts, active or revoked, and who confirmed them. It is not a wallet. It plugs into the wallets and apps that already exist. It is not on the signing path. If this code has a bug, an agent gets a wrong label. No funds move through it except operator bonds.

In the local demo the two operators are simulated with keys in a script and the confirmation is pre-signed. On mainnet the operators are real validators, starting with Silk Nodes, and the notice is signed the moment the stop lands.

FAQ

What if the owner's cold key is lost?

Guardians, if the owner named any, can pause the agent with a vote, and if the owner stays silent for a set delay they can revoke it. Guardians can never spend and can never revoke instantly, so a rogue guardian cannot brick an agent on a whim.

What if the cold key is stolen?

The thief can stop the agent, which is annoying, not catastrophic. Changing the cold key is time locked, so the owner sees the attempt coming. The cold key cannot move funds.

Can an app check whether an agent was allowed at the time of an old signature?

Yes. The switch keeps a history, and isTrustedAt(agentId, timestamp) answers for any past moment. Apps should judge old signatures by that, never by the current state, because current state on Monad can still be speculative for a moment.

Why not just let the wallet refuse?

Wallets should refuse too, and a MetaMask agent wallet plugin does exactly that. But the app side is the backstop: even a wallet that ignores the switch cannot get a revoked agent's transaction through an app that checks.

Who pays for this?

Registering and stopping cost normal Monad gas, a fraction of a cent. Reading the switch is free. Operators fund their own bonds.

Is this audited?

Not yet. It has a unit and fuzz suite, real signature vectors verified against Monad's precompiles, and a fork test against the mainnet staking precompile. A fuzzing campaign with Monad's Ultrafuzz and a human review of the bond and escrow paths are planned before mainnet.
